# Koki.m

手作業を無くす仕組みを作っています。データアナリスト。

*I build systems that remove manual work. Data analyst by day.*

---

### いま動いているもの

自分の家計と生活を、丸ごと自動化した仕組みを運用しています。作って終わりではなく、**止まったら自分が困る状態**で毎日動かしています。

| | |
|---|---|
| **記帳** | カード会社の利用通知メールを1分おきに読み、日付・店名・金額を取り出して家計簿へ。手入力は0件 |
| **訂正** | 分類が外れたら通知のボタンで直す。一度直した店は次から自分で正しい分類に入る |
| **照合** | カード5社の明細CSVを台帳と1件ずつ突合。直近は漏れ0件 |
| **取得** | 各社サイトへログインして明細・領収書を無人で取得 |
| **監視** | 定期・常駐あわせて30本以上。**止まったことに自分が気づける仕組みまで込み**で運用 |

---

### 公開しているもの

**[ledger-starter](https://github.com/koki0000000/ledger-starter)** — 上の「記帳」の部分を、他の人が動かせる形に切り出したもの。
Google Apps Script と Notion だけで動く。銀行にもカード会社にもパスワードを渡さない。三井住友・楽天カード・ビューカード対応。

**[Ledgermail](https://koki0000000.github.io/ledgermail/)** — 同じ仕組みを「Discord に住む経理担当」として見せたコンセプトページ。動くデモ動画つき。
